# Опора — демонстрация QR-паспортов

## Публикация на Vercel

1. Установите Node.js 20 или новее.
2. В терминале откройте папку проекта и выполните:

   ```sh
   npm install
   npx vercel
   ```

3. Войдите или создайте аккаунт Vercel и следуйте подсказкам CLI. Для пробной публикации подтвердите предложенные настройки проекта.
4. Чтобы опубликовать production-версию с постоянной ссылкой, выполните:

   ```sh
   npx vercel --prod
   ```

Альтернатива: загрузите проект в GitHub и импортируйте репозиторий в панели Vercel. Vercel использует `npm run build` и каталог `dist`; дополнительные переменные окружения не требуются.

## Локальный запуск

```sh
npm install
npm start
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Демо-аккаунты

- Администратор: `admin@demo.ru` / `demo1234`
- Специалист: `worker@demo.ru` / `demo1234`

В начальных данных есть пример опоры и трансформаторной подстанции. QR-код можно открыть в карточке опоры или ТП под демо-аккаунтом администратора.

## Важно: только демонстрация

Это статическая демонстрация без сервера и базы данных. Объекты, записи, фотографии и создаваемые аккаунты сохраняются в локальном хранилище браузера и видны только в этом браузере. У каждого посетителя своя копия демо-данных; изменения не передаются другим пользователям. Поэтому QR-коды начальных примеров можно открыть на любом устройстве, а QR-код объекта, созданного посетителем, сработает только в браузере, где этот объект был добавлен. Пароли демонстрационные и хранятся в браузере — не используйте этот проект для реальных или конфиденциальных данных.

QR-коды с опубликованного сайта открывают этот же адрес. Для реальной совместной работы потребуется серверная авторизация и общее постоянное хранилище.
